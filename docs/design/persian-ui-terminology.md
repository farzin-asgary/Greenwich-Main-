# Persian UI Terminology Dictionary

## Navigation & Actions
- **Continue Reading**: ادامه مطالعه
- **Start Reading**: شروع مطالعه
- **Favorites / Saved**: علاقه‌مندی‌ها
- **Add to Favorites**: افزودن به علاقه‌مندی
- **Remove from Favorites**: حذف از علاقه‌مندی
- **Save Changes**: ذخیره تغییرات
- **Publish**: انتشار
- **Cancel**: انصراف
- **Delete**: حذف
- **Archive**: آرشیو
- **Submit for Review**: ارسال برای بررسی
- **Back / Return**: بازگشت
- **View All**: مشاهده همه

## Book & Catalog Metadata
- **Author**: نویسنده
- **Translator**: مترجم
- **Publisher**: ناشر
- **Edition**: نسخه
- **Chapter / Section**: فصل / بخش
- **Description**: درباره کتاب / خلاصه داستان
- **Related Books**: کتاب‌های مرتبط

## Cafe & Dashboard
- **Request Demo**: درخواست دمو
- **Redeem Coupon**: دریافت کوپن / اعمال کوپن
- **Customer Panel**: پنل مشتری

## States
- **Loading**: در حال بارگذاری...
- **Saving**: در حال ذخیره...
- **Success**: عملیات موفق / تغییرات ذخیره شد
- **Error**: خطا در ارتباط / عملیات ناموفق
